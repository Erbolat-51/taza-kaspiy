Ты — ведущий full-stack разработчик команды. Мы делаем MVP для хакатона **Smart City Aktau** (Mangystau Hub).
Цель: рабочий, задеплоенный продукт, который на питче за 1 минуту показывает полный цикл

## 4. Модель данных (Prisma)

- **Zone** — участок побережья: `id, slug, nameKk, nameRu, kind (CITY_BEACH | WILD_COAST | PORT_INDUSTRIAL | RESORT | SETTLEMENT), polygon (Json GeoJSON), centerLat, centerLng`
- **TgUser** — `id, telegramId (BigInt unique), chatId, username, firstName, lang (kk|ru), role (RESIDENT | EXECUTOR), createdAt`
- **Report** — `id, code (ТК-0001), source (BOT|WEB), tgUserId?, lat, lng, zoneId?, comment?,
  photo, photoThumb, afterPhoto?, category (TRASH | PLASTIC | OIL | DEAD_ANIMAL | SEWAGE | CONSTRUCTION | OTHER),
  severity (1–5), aiConfidence, aiSummaryKk, aiSummaryRu, aiRaw (Json), categoryConfirmedByUser (bool),
  status (NEW | CONFIRMED | ASSIGNED | IN_PROGRESS | RESOLVED | REJECTED),
  executorId?, parentId? (дубликат), duplicatesCount, createdAt, assignedAt?, resolvedAt?, isDemo (bool)`
- **ReportEvent** — история: `reportId, type (CREATED | AI_CLASSIFIED | STATUS_CHANGED | ASSIGNED | AFTER_PHOTO | COMMENT), payload Json, actor, createdAt`
- **Executor** — исполнители: `id, nameKk, nameRu, kind (UTILITY | ECOLOGY | VOLUNTEER_ORG | ANIMAL_RESCUE), tgUserId?` (если привязан к Telegram — получает задачи в бот)
- **Cleanup** — субботник: `id, zoneId, title, startsAt, meetingPoint, maxVolunteers, status`
- **CleanupSignup** — `cleanupId, tgUserId, createdAt` (unique пара)
- **AdminUser** — `email, passwordHash, name, role (ADMIN | OPERATOR)`

## 5. Ключевая логика

**Приём репорта** (бот или веб): сохранить фото (sharp) → определить зону (точка в полигоне, иначе ближайшая зона в радиусе 3 км) → ИИ-классификация → проверка дубликатов → сохранить → `ReportEvent` → emit Socket.IO `report:new`.

**ИИ-классификация** (`server/src/ai/classify.ts`):
- Отправить фото в Claude vision. Попросить **строго JSON** по Zod-схеме:
  `{ isPollution: boolean, category, severity: 1-5, confidence: 0-1, summaryKk, summaryRu }`.
- В промпте: контекст — побережье Каспийского моря, Мангистау; как оценивать severity (1 — единичный мусор, 5 — нефтяное пятно или массовая гибель животных).
- Если `isPollution=false` — бот вежливо просит сделать другое фото.
- Таймаут 15 с, 1 повтор, при ошибке — fallback.
- **MOCK-режим** (нет ключа или ошибка): категория по ключевым словам комментария (kk/ru: «мұнай/нефть» → OIL, «итбалық/тюлень» → DEAD_ANIMAL, «пластик/бутылка» → PLASTIC …), иначе TRASH, severity 2. **Демо не должно падать никогда.**

**Дубликаты:** репорт в радиусе 50 м той же категории, открытый, за последние 48 ч → `parentId` = старый, у родителя `duplicatesCount++` и severity = max. На карте один маркер с бейджем «×N».

**Индекс чистоты зоны (0–100):** `100 − Σ(вес_severity × затухание_по_возрасту)` по открытым репортам зоны, clamp 0..100. Веса: 1→4, 2→8, 3→14, 4→22, 5→35. Затухание: 1.0 первые 7 дней, затем линейно до 0.5 к 30 дню. Цвет: ≥80 зелёный, 50–79 жёлтый, <50 красный. Пересчитывать при каждом изменении, кэшировать.

**Уведомления в Telegram:** автор получает сообщение при каждой смене статуса. При RESOLVED — фото «до/после» (media group) и «Рақмет! Жағалау тазарды 🌊».

## 6. Telegram-бот (UX важнее всего — это лицо демо)

Язык по умолчанию **казахский**, выбор kk/ru при /start. Короткие дружелюбные сообщения, эмодзи умеренно.

Главное меню (reply keyboard):
- 📸 **Ластануды хабарлау** — флоу: фото → геолокация (кнопка `request_location`, или можно прислать точку на карте) → комментарий (можно «Өткізу») → «⏳ ЖИ талдап жатыр…» → результат: «Анықталды: 🧴 Пластик қоқыс · Қауіптілік 3/5» + inline-кнопки «✅ Дұрыс» / «✏️ Санатты өзгерту» → «Хабарламаңыз тіркелді: ТК-0042. Картада: <ссылка>».
- 🗺 **Карта** — ссылка на веб-карту (или Telegram Web App кнопка).
- 🧹 **Сенбіліктер** — список ближайших субботников с кнопкой «Қатысамын».
- 📋 **Менің хабарламаларым** — последние 5 с их статусами.

Для **исполнителей** (role EXECUTOR): при назначении приходит задача с фото, адресом и локацией (`sendLocation`), кнопки «🚀 Жұмысты бастадым» → «✅ Орындалды» → бот просит фото «после» → статус RESOLVED автоматически. Это главный вау-момент демо: админ назначил — у исполнителя на телефоне пришла задача — он закрыл её фото.

Привязка исполнителя: в админке у Executor генерируется код, исполнитель отправляет боту `/link КОД`.

  Полигоны — узкие полосы вдоль реальной береговой линии. Сделай их приблизительными и вынеси в `server/prisma/seed/zones.geojson`: команда потом поправит координаты через geojson.io по OpenStreetMap. В README так и напиши: координаты приблизительные.
- **Исполнители:** «Қалалық коммуналдық қызмет», «Экология басқармасы», «Еріктілер штабы», «Жануарларды құтқару тобы».

## 11. Сценарий демо (всё должно работать именно так)

1. Открыта публичная карта на проекторе.
2. Участник отправляет в бот фото мусора на берегу + геолокацию.
3. Через ~5 с бот отвечает результатом ИИ, на карте появляется пульсирующий красный маркер и тост.
4. В админке репорт появился в колонке «Жаңа» → назначаем «Қалалық коммуналдық қызмет».
5. У исполнителя в Telegram приходит задача → «Орындалды» → фото «после».
6. Маркер становится зелёным, индекс зоны растёт, автор получает «до/после» и спасибо.

## 12. Заметки к реализации (решения по ходу работы)

- **Фаза 8 / прод за Caddy:** Fastify `trustProxy: true`, иначе rate limit видит IP Caddy, а не клиента,
  и все пользователи делят один лимит. Сейчас включается при `NODE_ENV=production` (`server/src/app.ts`) —
  проверить, что в Docker-образе `NODE_ENV=production`.
- **Фазы 3 и 6 / фото в Telegram:** отправлять **JPEG**, не webp (Telegram показывает webp как стикер/документ,
  media group «до/после» ломается). На диске храним webp; при отправке в бот конвертировать через sharp на лету
  (`sharp(file).jpeg({ quality: 85 })`) и слать как `InputFile(buffer)`.
- **БД:** Neon (Франкфурт), прямое подключение `sslmode=require`. `docker-compose.yml` с Postgres — для деплоя/локально.
- **Windows + curl:** кириллицу в `-F comment=...` передавать из UTF-8 файла (`-F "comment=<file.txt"`).
- **ИИ-бюджет:** общий бюджет 15 с на вызов; повтор (1 раз) только на 429 / 5xx / сетевые ошибки; на таймаут не повторяем.
- **Бот, результат ИИ (Фаза 3):** если `provider=mock` — не писать «ЖИ анықтады», а попросить выбрать категорию
  кнопками. Если `confidence < 0.6` — показать результат, но кнопки «✅ Дұрыс / ✏️ Өзгерту» выделить
  (явный вопрос «Дұрыс па?»).
- **ИИ-цепочка:** `AI_PROVIDER=auto` → claude (есть ключ) → clip (локально, дочерний процесс) → mock.
  Бот: `provider=clip` ведёт себя как claude («ЖИ анықтады» + правило confidence < 0.6); `mock` — выбор кнопками.
  В `aiRaw`: provider, model, top3. Windows: нужен VC++ Redistributable ≥ 14.40 (иначе CLIP → mock).
- **Фаза 8 / Docker:** модель CLIP (~150 МБ) кэшировать в volume `./models` или запекать в образ; onnxruntime-node
  на Linux работает без install-скрипта (CPU-бинарники в пакете).
